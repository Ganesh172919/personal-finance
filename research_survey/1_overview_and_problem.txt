SURVEY PART 1: PROJECT OVERVIEW AND PROBLEM DOMAIN

1. Project Summary
Personal Finance is a full-stack financial planning workspace built for local use. It combines a React frontend, an Express API, MongoDB-backed business logic, and a Python AI Core that runs a multi-agent financial analysis workflow.

The project is not just a budget tracker. It is designed to help users move from raw financial data to guided action through dashboards, AI chat, workflows, collaboration features, and automations.

2. Problem Domain
Many personal finance applications stop at recording data. They show transactions, balances, and charts, but they do not reliably answer higher-value questions such as:
- Where is money leaking month to month?
- Should the user prioritize debt repayment or investing?
- Can a future goal be funded without breaking the current budget?
- How should shared financial work happen inside a family or small team?

This project targets that gap by combining traditional finance tooling with structured AI reasoning and operational features around trust, automation, and collaboration.

3. Core Product Direction
The repository supports a finance platform with several layers of value:
- Personal finance operations: transactions, budgets, exports, journals, receipts, and analytics
- Decision support: AI-assisted chat, specialist financial analysis, and what-if style reasoning
- Collaboration: organizations, invites, comments, activity feeds, and notifications
- Automation: workflows, domain events, scheduled jobs, and autopilot planning
- Extensibility: marketplace, plugins, and connector-oriented runtime support

4. Why The Multi-Agent Layer Matters
The most distinctive part of the project is the AI Core. Instead of routing every request to one generic model prompt, the system uses a master agent plus specialist agents. This creates a more structured pipeline for financial reasoning and makes it easier to expose trace data such as the agents involved, the workflow steps, and the provider used.

5. Current Local State
The project is now aligned for stronger local execution:
- The AI Core correctly loads provider keys from `server/.env`
- Local auth works across both `localhost` and `127.0.0.1`
- Email verification remains in the flow, but the OTP is surfaced in development
- The onboarding and chat UX are more polished for demo and portfolio use
