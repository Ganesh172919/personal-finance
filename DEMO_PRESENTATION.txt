SET UP THE DEMO

Start MongoDB and run npm run dev from the repository root to start Express, AI Core, and the Vite client. Open http://127.0.0.1:5173/voice. See FINWISE_OPERATIONS.md for setup. Use a signed-in synthetic workspace. To enable a fresh workspace on a local development server with a test database, set DEMO_EVALUATOR_ENABLED=true and select Start a local demo workspace.

In Finance > Budgets, set this month's Food & Dining budget to INR 835. Use a workspace with no recorded expenses for the ₹785 preview. Run npm run verify:gnani and use dist/submission/demo/live-gnani-check.wav for the Hindi example. Keep credentials and personal records out of the recording.
